# KIT CV ATS LENGKAP — PAKET SIAP LAMAR KERJA

Versi 1.0 | Bahasa Indonesia

## Isi paket
1. Template CV ATS satu kolom yang bisa disalin ke Word atau Google Docs.
2. Panduan mengisi CV untuk fresh graduate dan kandidat berpengalaman.
3. Bank kata kerja pencapaian.
4. Contoh bullet pengalaman kerja dengan metode tindakan–konteks–hasil.
5. Template surat lamaran.
6. Template email pengiriman lamaran.
7. Checklist pemeriksaan ATS dan typo.
8. Tracker 30 lamaran kerja.

## 1. Template CV ATS

NAMA LENGKAP

- [Aplikasi/perangkat yang benar-benar dikuasai]

## 2. Aturan CV ATS
- Gunakan satu kolom, judul bagian standar, dan font sederhana.
- Hindari tabel, grafik, ikon, foto, header/footer rumit, dan kotak teks.
- Gunakan tanggal konsisten: Jan 2024–Mar 2025.
- Simpan PDF berbasis teks atau DOCX sesuai instruksi lowongan.
- Nama file: NamaLengkap_CV_Posisi.pdf.
- Jangan memasukkan kata kunci yang tidak sesuai kemampuan nyata.
- Jangan mengarang pengalaman, angka, sertifikat, atau pendidikan.

## 3. Bank kata kerja
Analisis: menganalisis, mengevaluasi, mengukur, mengidentifikasi.  
Operasional: mengelola, menjalankan, mengoordinasikan, memantau.  
Penjualan: menawarkan, menindaklanjuti, mempertahankan, mengonversi.  
Administrasi: mendokumentasikan, memverifikasi, mengarsipkan, menyusun.  
Teknis: membangun, menguji, memperbaiki, mengotomatisasi.

## 4. Contoh bullet yang kuat
Lemah: Bertanggung jawab melayani pelanggan.  
Lebih kuat: Melayani rata-rata [jumlah] pelanggan per hari, mencatat kebutuhan, dan menindaklanjuti keluhan sesuai SOP.

Lemah: Membuat laporan.  
Lebih kuat: Menyusun laporan [harian/mingguan] menggunakan [alat] agar tim dapat memantau [indikator].

Isi angka hanya jika dapat dibuktikan.

## 5. Template surat lamaran
Yth. Tim Rekrutmen [Nama Perusahaan],

Saya mengajukan lamaran untuk posisi [Nama Posisi]. Saya memiliki pengalaman/kemampuan dalam [2 kemampuan relevan] yang sesuai dengan kebutuhan posisi tersebut.

Dalam [pengalaman/proyek], saya [tindakan nyata] dan memperoleh [hasil yang dapat dibuktikan]. Saya tertarik bergabung karena [alasan spesifik dan jujur].

CV saya lampirkan untuk pertimbangan. Terima kasih atas waktu dan kesempatan yang diberikan.

Hormat saya,  
[Nama]  
[Nomor WhatsApp] | [Email]

## 7. Checklist sebelum kirim
[ ] Nama, nomor, dan email benar.  
[ ] Posisi dan perusahaan ditulis tepat.  
[ ] Pengalaman dan angka dapat dibuktikan.  
[ ] Kata kunci relevan dengan lowongan.  
[ ] Tidak ada tabel/kolom yang mengganggu pembacaan ATS.  
[ ] Ejaan dan tanggal konsisten.  
[ ] Format file sesuai instruksi perusahaan.  
[ ] Nama file profesional.

## 8. Tracker 30 lamaran
Salin tabel ini ke spreadsheet:

| No | Perusahaan | Posisi | Tanggal kirim | Kontak | Status | Tindak lanjut | Catatan |
|---|---|---|---|---|---|---|---|
| 1 | | | | | Disiapkan/Dikirim/Interview/ ditolak | | |
| 2 | | | | | | | |
| 3 | | | | | | | |

Ulangi baris hingga 30. Tindak lanjuti dengan sopan setelah 5–7 hari kerja jika tidak ada larangan dari perusahaan.

## 9. Rencana 7 hari
Hari 1: pilih 2 jenis posisi yang realistis.  
Hari 2: sesuaikan ringkasan dan keahlian dengan satu lowongan.  
Hari 3: perbaiki bullet pengalaman/proyek.  
Hari 4: periksa CV dan surat lamaran.  
Hari 5: kirim 3–5 lamaran yang benar-benar cocok.  
Hari 6: catat hasil dan siapkan jawaban wawancara.  
Hari 7: evaluasi respons dan perbaiki CV.

## Catatan penggunaan
Materi ini adalah alat bantu, bukan jaminan lolos ATS, dipanggil wawancara, atau diterima kerja. Sesuaikan setiap lamaran dengan lowongan dan pengalaman asli. Dilarang memalsukan kualifikasi.
